# საყვავილე — ერთგვერდიანი ვებგვერდის დემო

ქართული floral კონცეფცია რეალური ყვავილების მაღაზიისთვის: თაიგულების გაფილტვრადი დემო კატალოგი, შემთხვევები, შეკვეთის ტექსტის მოსამზადებელი ფანჯარა, გალერეის გადიდება და ბიზნესის Google Maps ბმული.

## დემოს განმარტება

ეს არის მფლობელისთვის საჩვენებელი, არაოფიციალური ვებგვერდის კონცეფცია. ბიზნესის სახელისა და Maps-ის წერტილის გარდა დეტალები დაუდასტურებელია. ფოტოები საილუსტრაციოა; ასორტიმენტი, სერვისები, პირობები და საკონტაქტო არხები მფლობელთან შესათანხმებელია. ფასები, ნომრები, საათები და სოციალური ბმულები არ არის გამოგონილი. დეტალები: SOURCES.md და CREDITS.md.

WhatsApp და დარეკვის ღილაკები ამჟამად დემო ფანჯრებს ხსნის: ისინი რეალურ შეტყობინებას ან ზარს არ იწყებს. შეკვეთის ტექსტის კოპირება მუშაობს. არაფერი იგზავნება სერვერზე ან ინახება ბრაუზერის საცავში. ანალიტიკა და გარე დამოკიდებულებები არ გამოიყენება.

## ფაილები

- index.html — მთავარი გვერდი, ქართულენოვანი შინაარსი და SEO.
- css/style.css — mobile-first დიზაინი, ფოკუსის ნიშნები და შემცირებული მოძრაობის მხარდაჭერა.
- js/script.js — მობილური მენიუ, კატალოგის ფილტრი, შეკვეთის ტექსტი და გალერეა.
- assets/images/ — ადგილობრივი ოპტიმიზებული WebP ფოტოები.
- assets/fonts/ — ადგილობრივი ქართული Noto ფონტები და ლიცენზიები.
- .nojekyll — სტატიკური ფაილების პირდაპირი გამოქვეყნებისთვის.

## ლოკალურად გაშვება

გაშალე არქივი და გახსენი index.html ბრაუზერში. ყველა ძირითადი ფაილი ადგილობრივია.

უფრო მოსახერხებელი დათვალიერებისთვის, პროექტის საქაღალდეში გაუშვი:

```bash
python3 -m http.server 8000
```

გახსენი http://localhost:8000. შეაჩერე სერვერი Ctrl+C-ით. ტექსტის კოპირება იყენებს ბრაუზერის ბუფერს; თუ წვდომა შეზღუდულია, ტექსტი მოინიშნება ხელით კოპირებისთვის.

## GitHub Pages

1. შექმენი GitHub რეპოზიტორია და ატვირთე ამ პროექტის შიგთავსი. index.html უნდა იყოს რეპოზიტორიის root-ში — არა დამატებით შიდა საქაღალდეში.
2. გახსენი Settings → Pages.
3. Source: Deploy from a branch.
4. აირჩიე main branch და / (root), შემდეგ Save.
5. დასრულების შემდეგ გახსენი GitHub-ის მიერ ნაჩვენები Pages ბმული.

CSS, JavaScript, ფონტები და ფოტოები ფარდობით ბილიკებს იყენებს, ამიტომ საიტი რეპოზიტორიის ქვე-ბილიკზეც მუშაობს. build, npm, framework ან სერვერული ნაწილი არ სჭირდება. საიტი ჯერ არ გამოქვეყნებულა.

## მფლობელის მონაცემების დამატება

js/script.js-ის დასაწყისში CONTACT ობიექტში null მნიშვნელობები მხოლოდ მფლობელის მიერ დადასტურებული მონაცემებით შეცვალე. phone ტელეფონისთვისაა; whatsapp — საერთაშორისო ნომერი (მხოლოდ ციფრები, მაგალითად ქვეყნის კოდით), ცალკე დასადასტურებელია. null ნომრებით დემო მოქმედებები უსაფრთხოდ რჩება. რეალური არხის დამატების შემდეგ განაახლე შესაბამისი განმარტებები HTML-ში.

instagram-ის ბმული ამჟამად არ აქტიურდება: ოფიციალური URL-ის დადასტურების შემდეგ დაამატე ნამდვილი ბმული HTML-ში და მოხსენი შესაბამისი TODO. ფოტოები, პროდუქცია, მომსახურებების ბლოკი, მიწოდების და მიღების პირობებიც მფლობელმა უნდა დაამტკიცოს.

robots ამ დემოსთვის noindex,nofollow-ია, რათა კონცეფცია ოფიციალურ ბიზნეს-საიტად არ დარეგისტრირდეს. საბოლოო ოფიციალურ ვერსიაში შეცვალე დამტკიცების შემდეგ. დაამატე საბოლოო დომენის canonical, og:url და აბსოლუტური og:image URL; დომენი აქ არ არის გამოგონილი. არსებული Open Graph ტექსტები ქართულადაა.

## შემოწმება

ბრაუზერის შემოწმების შედეგები იხილე QA.md-ში. ყველა ინტერაქცია vanilla JavaScript-ითაა შესრულებული. დიალოგებს აქვს Escape-ით დახურვა, ფოკუსის დაბრუნება და ფონზე დაჭერით დახურვა. გალერეას — კლავიატურის ისრები და მობილური გადაფურცვლა.
